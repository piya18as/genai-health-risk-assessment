# Gen-AI Based Health Risk Assessment and Personalized Health Recommendation System

An academic group project focused on assessing health risks associated with diabetes, cardiovascular disease, and related comorbidities using Machine Learning and Generative AI.

## Project Overview

The system aims to analyze user-provided health parameters, estimate potential health risks, and provide personalized health recommendations.

## Planned Areas

- Diabetes risk assessment
- Cardiovascular disease risk assessment
- Related comorbidity risk assessment
- Machine Learning based prediction
- Explainable AI for feature contribution
- Generative AI based personalized recommendations

## Technologies

- Python
- Machine Learning
- Generative AI
- Scikit-learn
- Pandas
- FastAPI
- React / Streamlit
- SHAP

## Project Status

🚧 Currently under development.
